# LightDetector

### Overview
LightDetector is a Space Engineers day/night detection script. It uses solar output to estimate ambient light and automatically control tagged lights. It automates lighting for bases, stations or vehicles.

### Features
- Day/night detection from solar production ratio.
- Automatic control for [DN] tagged lights.
- Manual test commands.
- LCD status display.

### Installation
Add Script_DayNightLights.cs to a Programmable Block, then tag controlled lights with [DN].

### Usage
Configure solar panels and lights, then run the script. Test commands can force or verify the behavior.
