## Français

### Présentation
LightDetector est un script Space Engineers de detection jour/nuit. Il utilise la production solaire pour estimer la luminosite et piloter automatiquement des lumieres taguees. Il sert a automatiser l'eclairage de bases, stations ou vehicules.

### Fonctionnalités
- Detection jour/nuit par ratio de production solaire.
- Controle automatique des lumieres taguees [DN].
- Commandes manuelles de test.
- Affichage d'etat sur LCD.

### Installation
Ajoute Script_DayNightLights.cs dans un Programmable Block, puis tague les lumieres a controler avec [DN].

### Utilisation
Configure les panneaux solaires et les lumieres, puis lance le script. Les commandes de test permettent de forcer ou verifier le comportement.

## English

### Overview
LightDetector is a Space Engineers day/night detection script. It uses solar output to estimate ambient light and automatically control tagged lights. It automates lighting for bases, stations or vehicles.

### Features
- Day/night detection from solar production ratio.
- Automatic control for [DN] tagged lights.
- Manual test commands.
- LCD status display.

### Installation
Add Script_DayNightLights.cs to a Programmable Block, then tag controlled lights with [DN].

### Usage
Configure solar panels and lights, then run the script. Test commands can force or verify the behavior.
